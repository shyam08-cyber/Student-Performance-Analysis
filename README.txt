STUDENT PERFORMANCE ANALYSIS SYSTEM
===================================

Files included:
- student_performance_analysis.py : Main Python project
- requirements.txt                : Required Python package

How to run:
1. Install Python 3.
2. Open Command Prompt in this folder.
3. Install the dependency using: pip install -r requirements.txt
4. Run the project using: python student_performance_analysis.py

The program asks for the number of students, their names, and marks in
five subjects. It then displays individual results and class analysis.
